# Bato (Smart Nepal Tourist & Trek Guide) — Features

Draft feature list (2026-11-05). Algorithms will be decided after the feature list is final.

**Priority key:**
- **Must-have** = the core app (must be finished)
- **Good** = adds marks
- **Wow** = stands out in the demo

---

## 1. User & Profile
| Feature | Priority |
|---|---|
| Sign up / login (email or Google) | Must-have |
| Traveller profile: age, fitness level, trekking experience, health conditions (asthma, heart, etc.) | Must-have (input to the risk predictor) |
| Preferences: budget, interests (nature, culture, adventure, religious), travel style (solo, family, group) | Good |
| Language: English / Nepali | Good |

## 2. Explore Places & Treks
| Feature | Priority |
|---|---|
| Browse places and treks by category (temples, lakes, viewpoints, treks, national parks) | Must-have |
| Detail page: photos, description, best season, entry fees/permits, how to get there, nearby places | Must-have |
| Interactive map with markers | Must-have |
| Search & filters (region, duration, budget, difficulty) | Must-have |
| Reviews & ratings from users | Good |
| "Near me" places using GPS | Good |

## 3. Trek-Specific Features
| Feature | Priority |
|---|---|
| Trek itinerary: day-by-day stages with altitude, distance and walking hours | Must-have |
| Altitude profile graph (elevation chart for each day) | Good |
| Difficulty & risk prediction personalised to the user | Must-have (core AI feature) |
| "Why this rating?" explanation (e.g. "risky because: beginner + 900 m altitude gain on day 4 + January") | Wow |
| Acclimatisation warnings and suggested rest days | Must-have |
| Permit info (TIMS, ACAP, Sagarmatha NP) with costs | Good |
| Teahouse/lodge list along the route | Good |
| Packing checklist generated by season and altitude | Good |

## 4. Trip Planner
| Feature | Priority |
|---|---|
| Add places to "My Trip" | Must-have |
| Automatically find the best visiting order and split it into days | Must-have |
| Estimated budget (transport, food, stay, permits) | Good |
| Save, edit and share a trip plan | Good |
| Show the planned route on the map | Good |

## 5. Smart & Recommendation Features
| Feature | Priority |
|---|---|
| "Recommended for you": treks and places matched to profile, season and budget | Good |
| "Best time to visit" suggestion per place | Good |
| Safer alternative suggestion: if a trek is too risky, suggest a similar but easier one (e.g. EBC → Poon Hill / Mardi Himal) | Wow |
| Weather forecast for the destination (weather API) | Good |

## 6. Safety Features
| Feature | Priority |
|---|---|
| SOS button: shares GPS location by SMS to emergency contacts | Wow |
| Emergency contacts: rescue, police, nearest health post, embassy | Good |
| Altitude sickness symptom checker: tick symptoms → "descend now" / "rest" / "OK" | Wow |
| Daily check-in: "Did you reach your next stop safely?" with an alert to family if missed | Wow (maybe future scope) |

## 7. Offline Mode
| Feature | Priority |
|---|---|
| Download trek details and maps for offline use | Good |
| Offline SOS (SMS works without internet) | Good |

## 8. Admin Panel (Web)
| Feature | Priority |
|---|---|
| Add or edit places, treks, stages and photos | Must-have |
| Manage users and reviews | Must-have |
| Dashboard: popular treks, user count, risk prediction stats | Good |
| Upload or retrain the ML dataset | Good |

---

## Suggested Scope

### Version 1 — Must finish
- Login + traveller profile
- Explore places/treks + map + search/filters
- Trek itinerary (day-by-day stages)
- Risk predictor with "Why this rating?" explanation
- Acclimatisation warning
- Trip planner with route ordering
- Admin panel

### Version 2 — If time allows
- Altitude profile graph
- Safer alternative suggestion
- Recommendations
- Budget estimate
- Weather forecast
- Packing checklist

### Future Scope — write about it in the report only
- SOS with live location tracking
- Daily safety check-in
- Altitude sickness symptom checker
- Offline maps
- Nepali language support
- Booking guides, porters and teahouses
